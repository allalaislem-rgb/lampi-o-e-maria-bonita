# Mathematical assumptions – DEVELOPMENT DEFAULTS

> **Status: NOT A CERTIFIED MATHEMATICAL MODEL.**
> Every value below was chosen by development so that the prototype is playable and lands
> roughly in the area of the GDD targets. All of it must be replaced by values the game
> mathematician produces and validates. All of it lives in **`src/config/gameConfig.ts`**,
> and none of it is hard-coded in game logic.

GDD targets (all unvalidated): **RTP 96.20 %**, **max win 10 000× total bet**, **high volatility** overall
(base high, Great Escape high, Hideout medium-to-high, Last Stand extreme).

## 1. Money & bets

| Item | Dev default | Notes |
|---|---|---|

## 2. Base game

**Reel model.** Each of the 15 positions is an independent weighted draw, using that reel's
weights (`BASE_REEL_WEIGHTS`). A reel can hold at most one of each scatter type. Weights stand in
for certified reel strips; the engine API stays the same when strips replace them.

| Symbol | Weight (each reel) | 3 / 4 / 5 pays (× line bet) |
|---|---|---|
| Lampião | 22 | 60 / 250 / 1250 |
| Maria Bonita | 25 | 50 / 200 / 900 |
| Hat | 30 | 40 / 150 / 600 |
| Cartucheira | 33 | 30 / 120 / 450 |
| Revolver | 36 | 25 / 90 / 350 |
| Sanfona | 40 | 20 / 75 / 300 |
| Rifles | 56 | 15 / 45 / 150 |
| Facão | 58 | 12 / 40 / 120 |
| Mandacaru | 60 | 10 / 30 / 90 |
| Cantil | 62 | 10 / 30 / 90 |
| Wild | 0 on reel 1, 20 on reels 2–5 | 60 / 250 / 1250 (pure wild line) |
| Wanted Poster | 8 | scatter |
| Hideout Map | 9 | scatter |
| Emblem | 7 | scatter |

**Evaluation rules (assumptions):**
- Only the highest win is paid on each line.
- A run of leading wilds pays as wild when that beats the substituted symbol.
- Wild does not substitute for scatters, and a scatter breaks a line.

**Random events** are rolled after the reels land and before evaluation, so they change the paid result:
- **Lampião's Arrival:** 1.2 % per spin. One reel (85 %) or two reels (15 %) out of reels 2–5 become fully Wild. Scatters on those reels are kept.
- **Cangaceiros' Raid:** 2 % per spin. Mode weights: cluster 55 (two or more of one low symbol), reel 35 (all low symbols on one reel), multi 10 (all low symbols on 2–3 reels). Target premium weights: Lampião 6, Maria 8, Hat 20, Cartucheira 22, Revolver 22, Sanfona 22.
- At most one event per spin. A Raid that would change nothing (fewer than 2 low symbols) is skipped.

## 3. Bonus triggers

- 3+ of a scatter anywhere triggers its bonus.
- **Simultaneous triggers:** the player chooses one feature and the others are forfeited (GDD §7 proposed rule; `simultaneousTriggerPolicy`).
- If the base win already reaches the max win, triggers are ignored and the round ends.
- The base-game win is paid together with the feature win when the round settles.

## 4. The Great Escape (Free Spins)

| Item | Dev default |
|---|---|
| Spins for 3 / 4 / 5 posters | 10 / 12 / 15 (GDD) |
| Free-spin reel weights | Low symbols slightly reduced. Wild weight on reels 2–5 is 28 / 26 / 24 / 22. Only Wanted Posters remain as scatters (weight 7) |
| Expanding Wild | Any Wild landing on reels 2–5 covers its whole reel |
| Escape Multiplier | Starts 1×, +1× after each **qualifying** spin, cap 10× (GDD) |
| Qualifying spin (assumption) | A spin where at least one winning line includes an expanding or raided Wild |
| Multiplier application (assumption) | The multiplier in effect before the spin applies to winning lines that include a Wild. Other lines pay 1× (`multiplierAppliesTo: 'wildWins'`; can be set to `'allWins'`) |
| Cangaceiro Raid | 7 % per free spin. 1 reel (80 %) or 2 reels (20 %) out of reels 2–5 that are not already wild become Wild. It does not use up a spin |
| Retrigger | 3+ posters → +5 spins. The multiplier is kept. Total spins capped at 50 |
| Bought entry | Posters awarded with weights 3: 80 · 4: 15 · 5: 5 |

## 5. The Hideout (Pick bonus)

| Item | Dev default |
|---|---|
| Board | 12 chests, generated by the engine when the feature starts and hidden from the client |
| Picks | 3 initial; extra picks allowed up to 8 picks in total |
| Prize weights | coins 46 · multiplier 17 · extra pick 10 (max 2) · Lampião's treasure 5 (max 1) · Maria's medallion 5 (max 1) · empty 13 |
| Coin values (× total bet) | 6 (30) · 10 (28) · 15 (20) · 25 (13) · 40 (6) · 75 (3) |
| Multiplier chest | +1× (75) or +2× (25), added to the bonus multiplier (starts 1×) |
| Lampião's treasure | fixed 60× bet |
| Maria's medallion | doubles the current bonus multiplier (assumption for "special multiplier upgrade") |
| Couple's Fortune | +100× bet once both specials are collected |
| Award | (coins + treasure + couple) × multiplier, capped at max win. Prizes already won are never lost |

The player's choices do not change the expected value: the board is random and symmetric.

## 6. The Last Stand (Hold & Respin)

| Item | Dev default |
|---|---|
| Grid / respins | 5×3; 3 respins; a new symbol resets to 3 (GDD) |
| Initial golds | Natural trigger: the landed emblem positions. Bought: 3 (70) / 4 (22) / 5 (8) random positions |
| Land chance | 9.8 % per empty position per respin |
| Landing symbol | gold coin 86 · multiplier 9 · Lampião's Emblem 5 |
| Coin values (× bet) | 1 (30) · 2 (26) · 3 (18) · 5 (12) · 10 (8) · 25 (4) · 50 (2) |
| Multipliers | 2× (55) · 3× (25) · 5× (14) · 10× (6). Multiple multipliers **add up**; the total multiplies the coin sum (assumption) |
| Lampião's Emblem | Carries a coin value. Effect: upgrade every locked multiplier one tier (2→3→5→10), 50 %, or add 1–3 gold coins to empty positions, 50 %. With no multiplier to upgrade, it adds positions instead |
| Grand Treasure | All 15 filled → +1000× bet, added **after** multipliers (assumption) |
| End | respins = 0, grid full, or max win reached |

## 7. Bonus Buy

| Feature | Price (× total bet, illustrative) |
|---|---|
| The Great Escape | 100 |
| The Hideout | 60 |
| The Last Stand | 200 |

Bonus Buy is disabled above a total bet of 20.00 (`maxBetForBuy`). The engine uses the same
feature math for bought and natural entries, and the GDD says Buy RTP must be modelled
separately. Market switch: `bonusBuy.enabled`.

## 8. Max win

10 000× total bet per round, applied on every route: base spin, all features, and bought
features. When it is reached the round ends and settles.
